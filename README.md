# Node.js Rest API 
*CRUD Rest API Node.js with Typescript, Express and MySQL.*

| Methods	| URL	| Actions
| -------- | ------- | ------- |
| GET | /api | Welcome Node.Js Rest API
| GET | /api/tutorials | Get all tutorials
| GET | /api/tutorials?title=xyz | Get tutorial filter for title (LIKE)
| GET | /api/tutorials/published | Get all published
| GET | /api/tutorials/:id | Get tutorial by id
| POST | /api/tutorials | Add new tutorial
| PUT | /api/tutorials/:id | Update tutorial 
| DELETE | /api/tutorials/:id | Remove tutorial

## Project setup
```
npm install
```

### Run
```
npm run start
```
